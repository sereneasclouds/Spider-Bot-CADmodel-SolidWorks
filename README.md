# Spider-Bot – SolidWorks CAD Model

## 📌 Project Overview

This repository contains the mechanical CAD model of a **Spider-Bot** developed using **SolidWorks**. The project focuses on the 3D modelling and mechanical design of a multi-legged robotic structure, including the main body, leg components, connecting links, and motor-related components.

The individual components have been designed and exported in **STEP (.step)** format for CAD interoperability and further development.

---

## 🎯 Project Purpose

The purpose of this project is to design and develop the mechanical structure of a **Spider-Bot** using 3D CAD modelling techniques.

The design focuses on:

- Developing the main robot body structure
- Designing the robotic leg mechanism
- Creating mechanical connecting links
- Designing motor connection components
- Developing modular components for assembly
- Providing CAD models suitable for further simulation, manufacturing, and prototyping

---

## 🛠️ Software Used

- **SolidWorks** – 3D CAD modelling and mechanical design
- **STEP (.step)** – CAD file exchange format

---

## 🤖 Design Features

The Spider-Bot CAD model includes:

- Multi-legged robotic structure
- Main body/base structure
- Modular leg components
- Leg fixing mechanism
- Mechanical connecting links
- Motor linkage
- Top structural component
- X-middle connecting link
- Individual components suitable for assembly and further development

---

## 📂 CAD Components

The repository contains the following CAD components:

| File | Description |
|---|---|
| `base link v5.step` | Base connecting link of the Spider-Bot |
| `base v11.step` | Main base/body component |
| `leg fixer v5.step` | Component used for fixing or mounting the robot leg |
| `leg part 2 v4.step` | Secondary leg component |
| `link for motor.step` | Mechanical link for motor connection |
| `spidy v43.step` | Main Spider-Bot model |
| `top new v5.step` | Top structural component |
| `x middle link v7.step` | Middle connecting link of the mechanism |
