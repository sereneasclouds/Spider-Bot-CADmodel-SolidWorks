# Spider-Bot – SolidWorks CAD Model

## Project Overview

This repository contains the mechanical CAD model of a **Spider-Bot that I designed and developed using SolidWorks**. The project focuses on the mechanical design and 3D modelling of a multi-legged robotic structure, including the main body, leg components, connecting links, and motor-related components.

I designed the individual components as part of the overall Spider-Bot mechanism and exported them in **STEP (.step)** format for CAD interoperability and further development.

## Project Purpose

I created this Spider-Bot as the mechanical foundation for one of my **ROS 2 robotics projects**. The CAD model was developed in SolidWorks and is used as the basis for simulating the robot in environments such as **RViz and Gazebo**.

I am particularly interested in **robotics simulation, ROS 2, and the development of robotic systems**, and I wanted to share this project as part of my learning and exploration in the field.

I hope this project can also be a starting point for collaboration. If you are interested in **ROS 2, Gazebo, RViz, robot simulation, mechanical design, or robotics projects**, feel free to reach out. I would be happy to connect and work together on interesting robotics simulation projects.

**Robotics is the future, and I am excited to keep learning, building, and exploring it. **

## Software Used

- **SolidWorks** – 3D CAD modelling and mechanical design
- **STEP (.step)** – CAD file exchange format

## My Design

The Spider-Bot I created consists of several interconnected mechanical components, including:

- Main base/body
- Leg components
- Leg fixing mechanism
- Motor linkage
- Top structural component
- Middle connecting links
- Supporting mechanical elements

The components were designed as individual parts to allow flexibility during assembly and future modifications.

## CAD Components

| File | Description |
|---|---|
| `base link v5.step` | Base connecting link designed for the Spider-Bot |
| `base v11.step` | Main base/body component |
| `leg fixer v5.step` | Leg fixing and mounting component |
| `leg part 2 v4.step` | Secondary leg component |
| `link for motor.step` | Mechanical link for motor connection |
| `spidy v43.step` | Main Spider-Bot model |
| `top new v5.step` | Top structural component |
| `x middle link v7.step` | Middle connecting link of the mechanism |

## File Format

The CAD components are provided in **STEP (.step)** format. This allows the models to be opened and further developed using different CAD platforms such as:

- SolidWorks
- CATIA
- Fusion 360
- Siemens NX
- Autodesk Inventor
